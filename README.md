# 花间集 Android 鲜花商城

这是一个可直接在 Android Studio 中运行的原生 Java 商城项目，包含用户账号、商品浏览、搜索、多花组合、模拟支付、订单管理、花语推荐和优惠活动完整流程。

## 功能

- 注册、登录、安全问答找回密码
- 首页搜索、品类筛选、真实广告图自动轮播，点击广告进入活动详情
- 花语推荐：按送花对象和场景匹配花材，并推荐相关商家
- 幸运轮盘：每天 3 次机会，抽取 20 元、15 元、5 元代金券
- 代金券在结算时选择并抵扣，使用记录随订单保存
- 首页找回密码入口与渐变化界面
- 五类固定鲜花商品：红玫瑰、紫玫瑰、康乃馨、菊花、茉莉花
- 商品详情、数量校验、加入购物组合
- 多花混搭、购物组合数量修改和金额汇总
- 微信支付/支付宝支付方式选择与模拟支付
- 支付成功后事务写入订单并扣减库存
- 我的订单列表与退出登录

## 数据存储

应用使用 Android 内置 SQLite 数据库 `flower_shop.db`，不依赖外部服务器即可完整演示。核心表：

- `users`
- `products`
- `merchants`
- `cart_items`
- `coupons`
- `lottery_draws`
- `orders`
- `order_items`

## 运行方式

1. 用 Android Studio 打开项目目录。
2. 等待 Gradle Sync 完成。
3. 选择模拟器或 Android 8.0 及以上真机。
4. 运行 `app` 模块。

演示账号：

- 账号：`demo`
- 密码：`123456a`
- 找回密码验证答案：`鲜花`

## 支付说明

课程项目中的支付流程会模拟跳转、等待和支付成功回调。接入真实微信或支付宝支付时，需要配置商户号、应用签名、回调地址和支付 SDK，不能仅凭客户端代码完成真实收款。
